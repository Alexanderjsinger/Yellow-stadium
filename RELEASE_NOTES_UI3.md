# Yellow Stadium — UI-3 PokéCenter + Storage Facelift Preview

Third controlled visual slice from Visual Design Bible v1.

## Included
- UI-1 shell/Journey and UI-2.1 Party/Bag remain intact.
- PokéCenter is reframed as a place first: compact Center title bar, room scene, Nurse dialogue, focused healing interaction, and persistent party-health summary.
- Existing healing timing game, free full-party recovery, forced-faint routing, audio cues and Journey return behavior are preserved.
- Pokémon Storage is now visually distinct from active Party management: classic box grid, patterned species/type tiles, selected-state marker, Box 1 · Kanto header, and a dedicated selected Pokémon action panel.
- Storage transfer actions reuse the existing Party add/remove/swap functions; View Details reuses the canonical Pokémon detail modal.

## Deliberately unchanged
Battle HUD/choreography, Cups, Safari, Pokédex and core progression are not redesigned in UI-3.

## Safety
No battle math, capture logic, AI, progression, save schema, audio ownership, healing semantics, inventory semantics or asset ownership changed. UI-3 stays inside the existing PokéCenter and Party owners.
